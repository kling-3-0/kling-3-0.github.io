# Kling Release Log

Kling 3.0 is a whole model series rather than one release: video, image, Omni variants and a new element library, reachable from four different clients.

**Read the full page:** https://kling-3-0.github.io/

The 3.0 line is aimed at people making multi-shot pieces, not single clips. The company describes a rebuilt architecture with multimodal instruction parsing, storyboard-level control across long sequences and native audio tied to the same identity as the visuals, which is a story about consistency between shots rather than raw prettiness in one. Access is straightforward: browser studio, mobile apps, a desktop build, or the API platform if you are wiring it into something. Pricing is not on the landing page and it differs between the consumer studio and the developer platform, so read both before you budget. If you would rather stay in one browser tab and generate video and images without picking a model family at all, Kyncept runs Veo 3.1 text and image to video alongside image generation.
